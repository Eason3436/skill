# OKX 網格回測：多頭網格 vs 空頭網格

用 OKX v5 **公開** API 的真實 K 線與資金費率，回測多頭 / 空頭 / 中性網格的收益率。
只用 Python 標準函式庫，**不需要 API 金鑰**。

## 結論摘要

| 指標（30 天滾動視窗平均，n=200） | 多頭網格 | 空頭網格 | 中性網格 |
|---|---:|---:|---:|
| 網格利潤（已實現） | +4.53% | +3.81% | +2.69% |
| 浮動盈虧（未實現） | −4.60% | −2.21% | −2.60% |
| 總報酬 | −0.39% | +1.43% | −0.13% |
| 平均最大回撤 | 10.56% | 6.17% | 4.10% |
| 對市場漲跌的迴歸斜率 | +0.77 | −0.25 | +0.16 |

三個發現：

1. **網格引擎本身幾乎沒有方向偏好。** 多空兩邊賺到的網格利潤差距不到 0.8 個百分點，
   收益率的全部差距來自持倉浮動盈虧，不是來自造市效率。
2. **網格沒有消掉方向風險，只是打了折。** 多頭網格對市場漲跌的斜率是 +0.77（R² 0.88），
   空頭是 −0.25，連「中性」網格都還有 +0.16 的殘餘斜率。
3. **空頭網格在這段樣本贏，是取樣造成的，不是結構優勢。** 把真實價格路徑繞進場價做幾何鏡像
   （p′ = 進場價² / p）後再測，空頭網格面對同幅度、同節奏的逆風虧得**更多**
   （大跌組 −23.51% vs 多頭網格的 −18.72%）。

## 回測方法

模擬 OKX 網格機器人的**實際掛單狀態機**，而不是簡化的「穿越價格就算成交」：

- 買單於第 i 格成交後，在第 i+1 格掛出賣單；賣單成交後在第 i−1 格補回買單。
- 多頭網格倉位恆 ≥ 0，空頭網格恆 ≤ 0（方向由 `fill()` 內的倉位上限強制）。
- 價格離開區間即停止成交、抱著倉位不動——等同真實 bot 未設止損時的行為。
- 網格區間取**開始日之前** N 天的最高最低價，避免用未來資訊設定參數。
- 資金費率按 OKX 實際結算值逐次計入（多頭付、空頭收）。

單根 K 線內的路徑不可知，收黑走 開→高→低→收，收紅走 開→低→高→收。此假設經
5m / 15m / 1H 三種解析度交叉驗證，結果差異在 0.2 個百分點內。

## 用法

```bash
# 1. 抓 OKX 公開資料（K 線 + 資金費率）
python3 fetch_okx.py --outdir data --days 210 --bar 15m

# 2. 引擎自我驗證（9 項合成路徑檢查，必須先過）
python3 test_engine.py

# 3. 單一區間實測
python3 grid_backtest.py --datadir data --days 90 --lookback 30 --grids 50

# 4. 滾動視窗 + 市場狀態分組
python3 rolling_study.py --datadir data --window 30 --step 3 --out rolling30.json

# 5. 樣本形狀診斷 + 參數穩健性掃描
python3 diagnostics.py --datadir data --rolling rolling30.json --scratch .

# 6. 同幅度配對比較
python3 symmetry.py --rolling rolling30.json

# 7. 鏡像對照檢驗（拆開「路徑形狀」與「網格數學」）
python3 mirror_test.py --datadir data

# 8. 產生 HTML 報告用的完整資料
python3 build_report_data.py --datadir data --out report_data.json
```

## 檔案

| 檔案 | 用途 |
|---|---|
| `fetch_okx.py` | 抓 OKX 公開 K 線與資金費率，寫成 CSV |
| `grid_backtest.py` | 網格引擎 + 單一區間回測 CLI |
| `test_engine.py` | 引擎自我驗證：來回一格的利潤、多空對稱性、倉位方向鎖、手續費、資金費、損益分解、出界停止交易 |
| `rolling_study.py` | 滾動視窗回測，依市場狀態分組彙總 |
| `diagnostics.py` | 樣本形狀診斷 + 14 組參數穩健性掃描 |
| `symmetry.py` | 同幅度配對比較（控制漲跌幅後的多空不對稱） |
| `mirror_test.py` | 幾何鏡像對照，區分路徑形狀與網格數學 |
| `build_report_data.py` | 一次跑完所有分析，輸出報告用的單一 JSON |
| `export_report.py` | 圖表資料匯出（散點、分組、淨值曲線） |

## 預設參數

投入 10,000 USDT · 1x 槓桿 · 50 格等差 · 掛單費 0.02% · 15m K 線 ·
標的 BTC / ETH / SOL / DOGE USDT 永續 · 網格區間取起始日前 30 天高低點。

## 限制

- 樣本僅 210 天、四個幣種，期間整體偏空（買入持有平均 −1.71%）。
- 滾動視窗高度重疊（每 3 天起一個 30 天視窗），勝率不是獨立試驗的統計量。
- 假設全部以掛單成交、零滑價，未模擬止損 / 止盈 / 手動重設區間。
- OKX 歷史資金費率端點僅回溯約三個月，較早的視窗低估此項成本。
- 1x 槓桿且不含強平，高槓桿下逆勢尾端的浮虧數字沒有意義。

回測結果不預測未來報酬，非投資建議。
