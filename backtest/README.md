# 布林通道分批進出場回測 · OKX 美股代幣

在 OKX 美股永續代幣（`instCategory=3`，共 131 檔）上回測一個布林通道均值回歸策略，
統計**建倉深度的發生率與次數（30% / 30% / 40%）**。

## 策略

布林通道：中軌 = 收盤價 `SMA(20)`，σ = 20 根母體標準差（ddof=0），逐根動態重算。

| 動作 | 觸發 | 倉位 |
|---|---|---|
| 進場批 1 | 最低價觸 中軌 − 1.5σ | 買 30% |
| 進場批 2 | 最低價觸 中軌 − 2.0σ | 買 30% |
| 進場批 3 | 最低價觸 中軌 − 2.5σ | 買 40% |
| 滿倉出場 | 最高價觸 +1.5σ / +2σ | 賣 60% / 賣 40% |
| 部分倉出場 | 只成交 1~2 批，最高價觸 +1.5σ（或 +2σ）| 全數了結 |

- **時間框架**：8H（由 2 根原生 4H 合成，OKX 無原生 8H）與 12H（原生）。
- **部分倉出場目標**：分別測試 `+1.5σ` 與 `+2σ` 兩種變體。
- 掛單成交於軌價本身；價格回到 0 倉即結束一個週期。

## 使用

```bash
# 1) 抓取全部代幣的 4H / 12H K 線（快取到 scratchpad，可重複執行不重抓）
TOKENS="AAPL-USDT-SWAP TSLA-USDT-SWAP ..." python3 fetch_data.py

# 2) 執行回測（自動從快取檔推導代幣清單）
python3 backtest.py            # 輸出 results.json + per_token.csv

# 3) 產生 HTML 報告
python3 build_report.py        # 輸出 report.html
```

可用環境變數 `BB_LENGTH`（預設 20）調整布林週期。

## 產出

- `results.json` — 四種情境（8H/12H × 部分倉出場 +1.5σ/+2σ）的彙總統計。
- `per_token.csv` — 逐檔明細。
- `report.html` — 視覺化報告。

## 限制

代幣多於 2026 年上市，樣本歷史短（8H K 棒中位數約 54 天），回測期偏多頭，
未平倉週期未計損益故損益與勝率具倖存者偏誤。未計手續費、資金費率、滑價與槓桿風險。
僅供研究，非投資建議。
