# OKX TSM 週末盤後→盤前 均值回歸回測

回測 OKX 代幣化美股 **TSM-USDT-SWAP**（台積電 TSMC）在美股休市的週末區間，
以「碰下軌買入、碰上軌賣出、週一盤前強制平倉」的均值回歸策略。

## 策略定義

- **標的**：`TSM-USDT-SWAP`（OKX category 3 股票代幣，永續合約，24/7 交易）
- **區間**：每個週五 **16:00 ET 收盤（盤後起點）** → 週一 **09:30 ET 開盤（盤前終點）**，
  共 65.5 小時，涵蓋週五盤後 + 週末 + 週一盤前。
- **錨定價 P0**：週五 16:00 ET 的代幣收盤價（最後一個正規盤價格）。
- **上下軌**（相對 P0 的百分比）：
  - 方案 A：下軌 −1.8%、上軌 +2%
  - 方案 B：下軌 −2%、上軌 +2%
- **進出場**（只做多，區間內可多次往返）：
  - 未持倉且 K 棒最低 ≤ 下軌 → 以下軌價買入
  - 持倉且 K 棒最高 ≥ 上軌 → 以上軌價賣出（停利）
  - 走到週一 09:30 ET 仍持倉 → 以區間最後一根 K 棒收盤價**強制平倉**
- **部位**：1 倍名目本金，交易間逐筆複利。
- **資料**：15 分鐘 K 線（觸價偵測用）；區間全落在美東夏令時 EDT（UTC−4）。

|---|---|---|
| 有進場的週末 | 8 / 18 | 6 / 18 |

> 「最大回撤 −0.57%」是已實現權益曲線的回撤（唯一一筆虧損：2026-05-08 強平 −0.57%）。
> 「持倉最大浮虧 −2.90%」是買進後、在強制平倉/停利前帳面一度虧損的最深幅度，較能反映實際持倉風險。

## 重要限制

- TSM 代幣約 2026-03 才上線，僅約 4 個月、18 個週末，**樣本數很小**，統計意義有限。
- 15 分鐘 K 線偵測觸價；假設限價單能剛好在軌價成交（未考慮滑點/流動性）。
- 未計入資金費率（永續合約週末仍可能收付資金費）。
- `candles_raw.txt` 為當次抓取的快照，重跑請用 `fetch.sh` 更新。
- 本回測僅為歷史數據分析，**非投資建議**。

## 增加買入機會的方案研究（`strategies.js`）

原始固定軌策略只有 8/18 週末進場（一半以上空手），因為價格必須跌破週五收盤
−1.8% 才買。以下研擬並回測多種「增加進場機會」的方案（同 18 週末、1x、15m）：

| 方案 | 進場週末 | 買入次數 | 總收益(毛) | 最大回撤 | 持倉浮虧 |
|---|---|---|---|---|---|
| S0 固定軌 −1.8/+2（基準） | 8/18 | 8 | +15.52% | −0.57% | −2.90% |
| S1 加碼馬丁 −1/−1.8/−2.6 停利+2 | 11/18 | 11 | +10.34% | −0.57% | −2.90% |
| S1b 加碼 −0.8/−1.6/−2.4 停利+1.5 | 12/18 | 13 | +9.02% | −0.78% | −3.09% |
| **S2 追蹤回檔 1.5% 停利+2** | **15/18** | 23 | **+21.00%** | −2.36% | −3.41% |
| S2b 追蹤回檔 1.0% 停利+1.5 | 18/18 | 33 | +21.94% | −3.83% | −3.90% |
| S3 網格 −1~−5% 每格停利+1 | 11/18 | 34 | +6.14% | −0.28% | −1.75% |
| S3b 網格 −0.8~−4% 每格停利+1 | 12/18 | 51 | +9.29% | −0.47% | −2.29% |

**核心洞察**：只有「**追蹤回檔買入**」（把錨定價從固定週五收盤，改成隨新高滾動的
running-high，價格自高點回落 d% 就買）能同時**增加進場**又**提高收益**——因為它在
「價格從沒跌破週五收盤」的上漲週末也能買到回檔。加碼與網格增加成交次數，但停利被
+1~2% 綁死＋攤平成本，反而稀釋收益。

### 追蹤回檔參數掃描（毛 vs 淨 0.05%/邊）

| 參數（回檔/停利） | 進場週末 | 買入次數 | 毛收益 | 淨收益 | 最大回撤(淨) |
|---|---|---|---|---|---|
| dip1.00 / tp2.0 | **18/18** | 31 | +27.24% | +23.35% | −4.12% |
| dip1.25 / tp2.0 | 16/18 | 27 | +24.97% | +21.64% | −3.39% |
| dip1.50 / tp2.0 | 15/18 | 23 | +21.00% | +18.24% | −2.65% |
| **dip2.00 / tp2.0** | 14/18 | 22 | +28.31% | **+25.52%** | **−2.80%** |

**建議**：
- **要「每個週末都有進場」** → 追蹤回檔 1.0% / 停利 +2%（18/18，淨 +23%，但回撤 ~−4%）。
- **要「多進場＋最佳報酬/回撤」** → 追蹤回檔 2.0% / 停利 +2%（14/18＝基準的近兩倍，
  淨 +25.5%，回撤僅 −2.8%）。
- 追蹤法交易次數多，**手續費侵蝕明顯**（33 筆約吃掉 4%），務必用限價（maker）降低成本。

## 重現方式

```bash
npm install -g @okx_ai/okx-trade-cli
bash fetch.sh                 # 更新 candles_raw.txt（15m K 線）
node backtest.js 0            # 原始固定軌：毛收益
node backtest.js 0.0005       # 原始固定軌：淨收益
node backtest.js 0 0.015 0.02 # 自訂下軌/上軌，如 -1.5/+2
node strategies.js            # 增加買入機會的多方案比較 + 追蹤回檔掃描
```
